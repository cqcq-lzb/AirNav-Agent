## 代价函数总览

支气管镜路径规划用的是**多代价 A\***。搜索状态不是单个节点，而是
「(上一个节点, 当前节点)」这一对，这样才能把转弯角度纳入代价。

每条候选路径的总代价由四项加权重组成：

```
edge_cost = w_length    * length_term
          + w_radius    * radius_term
          + w_curvature * curvature_term
          + w_branch    * branch_term
```

四项的单位都是「毫米当量」——都乘了 `step_mm`，所以量纲一致、可以直接加权求和。
这一点很关键：如果一个项忘了乘步长，它在长路径上就会被系统性低估。

## 长度项 length_term

`length_term = step_mm`

就是这一段的几何长度。权重固定为 1.0 的量级，作为其余三项的比较基准。

## 半径项 radius_term

`radius_term = step_mm * (2.0 / max(local_radius, 0.25)) ** 2.0`

`local_radius` 取当前节点与下一节点中较小的气道半径（mm）。这一项衡量「这段路有多窄」，
是**平方反比**形式：半径减半，代价涨到 4 倍。

- 半径 1.0mm（直径 2.0mm）时，系数 `(2.0/1.0)^2 = 4.0`
- 半径 2.0mm（直径 4.0mm）时，系数 `(2.0/2.0)^2 = 1.0`
- 半径 4.0mm（直径 8.0mm）时，系数 `(2.0/4.0)^2 = 0.25`

分母上的 `max(local_radius, 0.25)` 是下限保护：中心线半径偶尔会被算成接近 0
（例如骨架与距离场在末梢的数值噪声），不设下限会得到天文数字的代价。

## 转弯项 curvature_term

```
free_angle = 15°（math.radians(15.0)）
excess     = max(0.0, angle - free_angle)
curvature_term = step_mm * (excess / pi) ** 2
```

注意三个细节：

1. **有 15° 的死区**。小于 15° 的偏折不计代价。中心线是逐体素骨架化来的，
   天然带锯齿噪点，不设死区的话会被噪声主导。
2. **超过死区的部分才平方**，而且是除以 π 归一化后再平方。
3. 平方使得「一个大弯」比「两个中弯」更贵，这符合支气管镜的操作直觉：
   镜子过急弯时扭矩传递会明显变差。

## 分叉项 branch_term

```
branch_term = step_mm * (angle / pi) ** 2   # 仅当 degrees[current_node] >= 3
branch_term = 0.0                            # 否则
```

只有在**分叉点**（度 ≥ 3）上才计这一项，而且这里没有死区——用原始 `angle` 而不是 `excess`。

为什么单列一项？因为在分叉处转弯，镜子不仅要过这个几何弯，还要**选对分支**。
进错分支后回撤重来，代价远高于在直道上多走几毫米。所以分叉处的转弯应当比
同样的转弯出现在直道上更贵。

## 权重表

| 配置名 | 中文名 | length | radius | curvature | branch |
|---|---|---|---|---|---|
| `balanced` | 平衡型 | 1.00 | 1.50 | 0.35 | 0.80 |
| `wide_airway` | 宽气道优先 | 0.90 | 3.30 | 0.28 | 0.68 |
| `gentle_turn` | 平缓转弯优先 | 1.05 | 1.65 | 0.84 | 1.92 |

## 权重设计的可解释读法

- **radius 权重从 1.50 提到 3.30（×2.2）** 就是「宽气道优先」的全部含义：
  愿意多走路（length 降到 0.90），换更粗的气道。半径项是平方反比，
  再乘 2.2 倍权重，实际会把路径强烈推向主干。
- **curvature 0.35 → 0.84（×2.4）、branch 0.80 → 1.92（×2.4）** 是「平缓转弯优先」：
  两项同时提到 2.4 倍，代价是长度权重升到 1.05（愿意接受更长的路）。
  由于分叉项没有死区、转弯项有 15° 死区，这个配置对分叉处的取舍尤其敏感。
- 三档配置的 length 权重都在 0.90~1.05 之间，差别很小。这是刻意的：
  长度不是临床关注点，气道条件和操作难度才是。

## 分项归因的意义

同一个总代价可能有完全不同的构成。两条路径总分一样，一条可能是「短但窄」，
另一条是「长但宽」——临床含义完全不同。所以解释「为什么选这条」时，
**不能只报总分，必须报四项各自的贡献**。

工具 `explain_route_choice` 就做这件事：把胜出路径和落选路径分别沿路径重放代价函数，
累加出四项各自的总和，让人直接看到取舍发生在哪一项上。
