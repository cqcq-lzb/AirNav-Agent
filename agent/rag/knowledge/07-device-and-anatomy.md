## 免责说明（先读这一节）

本条目里的器械尺寸与解剖命名是**公开的领域通用参考值**，用来帮助理解
「器械外径」「安全余量」这些规划参数在真实操作中意味着什么。

它们不是本系统的实测数据，也不是器械选型的依据。
**具体用哪根镜子、哪个器械，是操作医生的判断**，本系统只负责回答
「在给定的外径与余量下，气道几何是否允许通过」。

## 器械外径的常见量级

粗细差别很大，规划时填错外径会得到完全不同的结论：

| 类别 | 外径量级 | 备注 |
|---|---|---|
| 超细支气管镜 | 约 2.8 ~ 3.2 mm | 工作通道很细，约 1.2 mm 级 |
| 常规诊断镜 | 约 4.9 ~ 6.2 mm | 工作通道约 2.0 ~ 2.8 mm |
| 治疗镜 | 约 6.2 ~ 6.9 mm | 工作通道约 2.8 ~ 3.2 mm |
| 径向超声探头（RP-EBUS） | 约 1.4 ~ 1.7 mm | 常配合引导鞘使用 |
| 活检钳 / 毛刷 | 约 1.8 ~ 1.9 mm | 经工作通道送入 |
| 冷冻探头 | 约 2.4 mm | |

注意一个容易混淆的点：**镜体外径 ≠ 工作通道直径**。
规划时要填的是「真正要伸到目标位置的那个东西」的外径。
如果是超细镜配合 1.9mm 活检钳，且钳子要伸出镜外到达外周气道，
那么决定能否通过的是**钳子经过的最远端气道的几何**，
而不是镜体本身的位置。

## 安全余量的含义

```
required_radius = 器械外径 / 2 + 安全余量
```

余量的作用不是「留点富余」，而是**覆盖三类误差**：

1. **分割误差**：气道边界本身有 ±1 个像素级的不确定。
2. **配准与呼吸误差**：CT 是静态的，实际操作中气道随呼吸形变，
   且导航系统与真实解剖之间存在配准偏差。
3. **器械偏移**：镜子在腔内不是沿中心线走，会贴壁。

默认 0.2mm 是一个偏保守的工程默认值。余量设得越大，
可通过的路径越少——设到 1.0mm 以上时，很多外周目标会直接判为不可达，
这时要结合具体情况判断是调整余量还是承认该目标不适合经支气管路径。

## 最窄余量怎么读

`minimum_clearance_mm = 最小半径 −（器械半径 + 安全余量）`

- **< 0**：不成立，规划阶段就已经把这条路剪掉了，不会出现在结果里。
- **0 ~ 0.5mm**：极度勉强。即使几何上「刚好过」，实操中基本不可靠。
- **0.5 ~ 1.0mm**：紧。需要操作经验，且应提示风险。
- **> 2.0mm**：相对从容。

报告里给「最窄余量」这个数字，比给「最窄直径」更有用，
因为余量已经把器械尺寸折算进去了，可以直接判断松紧。

## 支气管分段命名（Boyden 记法）

用 `B<数字>` 表示各段支气管。右肺 10 段、左肺通常按 9 段计（B1+2 合并）。

**右肺**

| 记号 | 段名 |
|---|---|
| RB1 | 尖段 |
| RB2 | 后段 |
| RB3 | 前段 |
| RB4 / RB5 | 中叶外侧段 / 内侧段 |
| RB6 | **背段**（下叶上段） |
| RB7 | 内侧底段 |
| RB8 | 前底段 |
| RB9 | 外侧底段 |
| RB10 | 后底段 |

**左肺**

| 记号 | 段名 |
|---|---|
| LB1+2 | 尖后段 |
| LB3 | 前段 |
| LB4 / LB5 | 上舌段 / 下舌段 |
| LB6 | **背段**（下叶上段） |
| LB7 | 内侧底段（常与相邻段融合） |
| LB8 / LB9 / LB10 | 前底段 / 外侧底段 / 后底段 |

「背段」（B6）是下叶的一个独立段，开口位置靠上、走向常与相邻段成较大角度，
是外周病灶定位里出现频率很高的目标。当用户提到「右下叶背段」，
指的就是 RB6。

## 分段名与系统的拓扑记号不是一回事

本系统的 `S163` / `J78` 是**图上的连通域编号**，与上面的 B 编号**没有对应关系**。
`S163` 只是「第 163 号连续气道段」的意思。

不要试图把 `S` 编号翻译成解剖段名。要做解剖定位，需要另外的
气道分段标注（V1 里有 `segment_labels`，但那是图分段的标签，
不是解剖命名）。汇报时如果要提解剖位置，应当来自影像判读，而不是从记号猜。

## 一个实用的换算

知道目标气道的直径后，能粗略反推「大概能容纳多粗的器械」：

```
可用器械外径 ≈ 2 × (气道半径 − 安全余量)
```

最窄直径 5.915mm（半径 2.957mm）、余量 0.2mm 时，
可用外径约 2 × (2.957 − 0.2) = 5.51mm。这只是几何估算，
实际还要看转弯、器械柔顺性和操作路径。工具 `scan_device_fit`
做的就是在这个几何约束下二分查找最大可行外径。
