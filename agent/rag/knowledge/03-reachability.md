## 分级的定义

可达性由「靶点到气道中心线的最近距离」决定，单位 mm：

| 上界 | 分级 | 含义 |
|---|---|---|
| ≤ 15 | `adjacent` | 紧邻气道，支气管镜路径可达性好 |
| ≤ 30 | `reachable` | 位于气道邻近区域，可规划路径，需关注远端细小气道连通性 |
| ≤ 50 | `marginal` | 明显偏离气道，当前气道树覆盖可能不足，需人工复核 |
| > 50 | `unreachable` | 远离气道，分割结果无法覆盖，不建议作为支气管镜导航目标 |

## 为什么必须有这一层

没有它的时候会出现一个很危险的假成功：结节在距气道 47.6mm 的位置，
规划器仍然返回了一条长度 6.3mm 的路径——因为它在气道图上找到了「离结节最近的一个节点」，
但那个节点其实在气管附近，路径终点离结节十万八千里。

对 GUI 来说这只是画面上一条短短的线，不会有人误读；但对 Agent 来说它**是成功的返回值**，
如果不加判据，模型会理直气壮地告诉用户「已规划出一条 6.3mm 的路径」。

所以 `marginal` 与 `unreachable` 的核心作用是**把假成功变成可解释的拒绝**。

## 这不是临床阈值

这一点必须在任何面向医生的输出里讲清楚：

- 15 / 30 / 50 这三个数是**工程口径**，用来让 Agent 有个一致的分级说法，
  不是从临床指南里抄来的。
- 真实的可达性还取决于：病灶与气道之间的实际解剖关系、是否存在可穿刺的邻近气道壁、
  呼吸运动导致的配准误差、操作者的经验。
- 因此这几个分级只能用于「提示需要复核」，不能用于「判定能不能做」。

面向用户的表述应当是「该目标距气道中心线 47.6mm，超出当前气道分割覆盖范围，
建议人工复核」，而**不是**「这个结节无法取样」。

## 各分级对应的行为

- `adjacent` / `reachable`：正常给出方案，可以继续做器械选型和出图。
- `marginal`：给出方案，但必须同时给出「需人工复核」的提示，不能只说结论。
- `unreachable`：应当明确说明不适合作为经支气管导航目标，并建议改用其他目标
  （此时可以调 `rank_candidates` 看有没有更好的候选）。

## 与靶距这个数字的关系

`target_distance_mm` 是靶点到中心线的最近距离，也就是分级所依据的原始数字。
它和路径长度是两回事：路径长度是镜子走的路，靶距是路尽头到病灶还剩多远。

两个数字要一起报。一条 291mm 的路径配 24mm 的靶距，
和一条 216mm 的路径配 12.5mm 的靶距，临床含义完全不同。

## 靶距在评分里的位置

候选路径的排序分数是：

```
score = A* 代价 + 2.0 * 靶点距离
```

靶距被乘了 2.0 的系数加进总分，因此它在选目标时是有分量的，
不只是事后报告的一个数字。系数取 2.0 是 V1 的既有取值，Agent 层未做改动。
